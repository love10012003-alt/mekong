# mekong.lal.vn - Tour Miền Tây Private

## Cách đẩy lên GitHub
1. Tạo repo mới trên github.com, ví dụ `mekong-lal-vn`
2. Tải toàn bộ file trong thư mục này lên repo, giữ đúng cấu trúc: `index.html`, `tour-can-tho.html`, `tour-con-thoi-son.html`, `assets/hero-wife.jpg`, `sitemap.xml`, `robots.txt`
3. Vào Settings > Pages > Branch: main, Folder: / (root) > Save
4. Trỏ domain mekong.lal.vn về GitHub Pages theo hướng dẫn của GitHub, hoặc dùng domain github.io trước để test.

## SEO đã chuẩn hóa
- Tiêu đề mỗi trang dưới 60 ký tự, chứa từ khóa chính
- Mô tả mỗi trang 150-160 ký tự, chứa từ khóa và CTA
- Thẻ H1 duy nhất mỗi trang, H2 theo lịch trình
- OG / Twitter Card, canonical, robots, sitemap
- Ảnh hero có alt mô tả, tên file hero-wife.jpg
- JSON-LD TravelAgency
